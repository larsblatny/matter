# Examples

Here you will find some example setup files. The setup can be done using either C++ or using Python.

### Using C++

An example file can be copied to the `src` directory and renamed `mpm.cpp`.
(Alternatively, change the `CMakeLists.txt` files)

### Python

Simply run any Python file like this:
`PYTHONPATH=<path_to_matter>/build/python python3 my_example.py`
